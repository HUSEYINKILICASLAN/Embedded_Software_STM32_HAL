In this example, i used STM32 NUCLEO-F030R8 MB1136 C-04 development board for using the internal temperature sensor and communication with USART2 virtual com port on pooling mode. Development board's USART2 terminal communication that i used it because of identified to virtual com port. I sent internal temperature datas and i saw the datas with HERCULES version 3.2.8 serial port viewer.
