In this example, I used the STM32 NUCLEO-F030R8 (MB1136 C-04) development board with a ADXL345 triple axis accelerometer. After initially creating the project with I2C1 enabled and configuring pins PB6 and PB7 as SCL and SDA, I wrote adxl346.c and adxl345.h files. And i pasted adxl345.h file into the main.c folder within the project directory. Next, i saw the axis datas while running with live expression of CubeIDE.
