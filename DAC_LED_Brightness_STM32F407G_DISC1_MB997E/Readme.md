In this example, I used the STM32F407G-Disc1 MB997E Discovery Development Board because of onboard DAC peripheral. I used DAC_CHANNEL_2 and pin PA5 for analog output. I connected PA5 pin to external green LED's positive terminal and 1k ohm resistor to LED's negative terminal and development board's GND pin. So LED brightness increased with 5 ms interval.
