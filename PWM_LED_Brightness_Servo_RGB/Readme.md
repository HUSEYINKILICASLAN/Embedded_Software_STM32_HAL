In this example, using an STM32 NUCLEO-F030R8 MB1136 C-04 board, I generated PWM via Timer1 to change the LED brightness from one channel. Channels 2, 3, and 4 generated the colors of the RGB LEDs. I drove the MG995 servo motor between 0 and 180 degrees using PWM via Timer3. For Timer1, I used pins PA8, PA9, PA10, and PA11 respectively. For Timer3, I used channel 1, PA6. I used 1K resistors to drive the LEDs. I connected 5V and GND to the servo via the board. The LED brightness increases by 0, 25, 50, 75, and 100 duty cycles per second. The RGB colors change with each button press and stay lit at 100 duty cycles. The servo continuously switches between 0 and 180 degrees.
