In this example, i used STM32 NUCLEO-F030R8 MB1136 C-04 development board for calculate time with systick timer. I wrote milisecond, second, minute variables for calculating with systick handler. Then i added the millisecond, second, and minute variables using the `extern` keyword so they could be used in the `main.c` file. I wrote the code within the `while` loop to toggle the LED every second.
