In this example, i used STM32 NUCLEO-F030R8 MB1136 C-04 development board for using TIM1 timer in interrupt mode. I used HSI clock source, so i have 48MHz clock. I want to use led on the board and toggle with 0.5 ms period. Prescaler 48000-1 and Counter Period (ARR value) 500-1. I saw the values of Current_Time, Total_Time and Counter variables on Live Expressions.
