In this example, i used STM32 NUCLEO-F030R8 MB1136 C-04 development board for UART communication with interrupt mode. Development boards USART1 terminal communication that i used it. And PA9/PA10 pins connected to CP2102 USB-TTL converters RX and TX pins. I type the 'blink' command followed by the number of seconds I want the LED to stay on, and send it via UART. USB-TTL converter connected to COM7 port on my pc and 38400 baudrate. I send the messages with HERCULES version 3.2.8 serial port viewer.
