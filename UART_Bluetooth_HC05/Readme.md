In this example, i used STM32 NUCLEO-F030R8 MB1136 C-04 development board for UART communication with HC-05 bluetooth module. Development board's USART1 terminal communication that i used it. And PA9/PA10 pins connected to HC-05 module RX and TX pins. I connected the HC-05 module to a tablet and i sent "selamlar" text to the module. Development board's UART setting was 9600 baudrate.
