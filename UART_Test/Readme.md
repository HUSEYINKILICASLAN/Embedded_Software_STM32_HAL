In this example, i used STM32 NUCLEO-F030R8 MB1136 C-04 development board for UART communication. Development boards USART1 terminal communication that i used it. And PA9/PA10 pins connected to CP2102 USB-TTL converters RX and TX pins. I send my name and surname with 1.5 second waiting time. USB-TTL converter connected to COM9 port on my pc. I saw the messages which came to pc that with PUTTY serial port viewer.
